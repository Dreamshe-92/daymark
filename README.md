# Daymark · 每日记（静态版）

Windows 电脑屏幕的壁纸式个人桌面：全屏壁纸，番茄钟、待办清单、重要日子倒计时是附带工具，平时不显示，通过一个可拖动的小圆点加圆环菜单打开。单文件 `index.html`，无构建、无依赖，直接用浏览器打开即用，数据存在浏览器本地（localStorage）。

## 界面

- **壁纸桌面**：全屏壁纸，右上角是大时钟、日期、当日小结和倒计时提醒；没使用时小结行不显示，有内容才出现。
- **小圆点**：像苹果手机 AssistiveTouch 的小圆点，46px 半透明，可任意拖动，松手吸附到最近的屏幕边缘并藏起大半，只露约 15px；点一下打开圆环菜单。
- **圆环菜单**：三个 120° 扇形（红番茄钟、蓝待办、橙重要日子），指针方向决定高亮，点中心、点圆环外或按 Esc 取消，按 1 / 2 / 3 直接打开。

## 功能

- **番茄钟**：专注 25 分钟 / 短休息 5 分钟 / 长休息 15 分钟，4 个番茄后自动进入长休息；环形进度、今日番茄数、今日专注时长、连续打卡天数；结束时有提示音；快捷键空格开始/暂停、R 重置、S 跳过。
- **待办清单**：添加、勾选（先画勾再扫删除线）、删除，按全部 / 进行中 / 已完成筛选，一键清除已完成。
- **重要日子**：添加日子与日期，自动算剩余天数，按最近排序；右上角会提醒最近的日子（名字、剩余天数、日期，当天显示“就是今天”）。

## 数据

待办、日子、番茄记录和小圆点位置都存在浏览器本地，关掉页面也不会丢；换浏览器或清缓存会清空。

## 使用

直接用浏览器打开 `index.html` 即可；也可以部署到 GitHub Pages：

仓库 Settings → Pages → Branch 选择 `main`，保存后访问 `https://<用户名>.github.io/daymark/`。
