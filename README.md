# Daymark · 每日记（静态版）

Windows 电脑屏幕的壁纸式个人桌面：全屏壁纸，番茄钟、待办清单、重要日子倒计时是附带工具，平时不显示，通过一个可拖动的小圆点加圆环菜单打开。单文件 `index.html`，无构建、无依赖，直接用浏览器打开即用，数据存在浏览器本地（localStorage）。

## 界面

- **壁纸桌面**：全屏壁纸，右上角是大时钟、日期、当日小结和倒计时提醒；没使用时小结行不显示，有内容才出现。
- **小圆点**：像苹果手机 AssistiveTouch 的小圆点，46px 半透明，可任意拖动，松手吸附到最近的屏幕边缘并藏起大半，只露约 15px；点一下打开圆环菜单。
- **圆环菜单**：三个 120° 扇形（红番茄钟、蓝待办、橙重要日子），指针方向决定高亮，点中心、点圆环外或按 Esc 取消，按 1 / 2 / 3 直接打开。
- **桌宠阿绒**：住在左下角的小狐狸，平时会随机做小动作（打瞌睡、伸懒腰、打哈欠、玩线团、追尾巴、打滚等），可拖动、可甩抛（带重力弹跳和压扁回弹）、可一键隐藏（隐藏后左下角留爪印按钮点回来）；点它会有心情回应（开心、害羞、挠痒笑，戳多了会生气晕倒），长按、右键或点头顶状态条打开菜单（摸摸、喂食、玩耍、睡觉、状态、音效开关）；它会隔几分钟碎碎念，头顶有状态条；摸摸喂食涨亲密度（陌生→熟悉→亲密→挚友），饱食度会慢慢下降，饿了会主动要吃的；每周一进化一次（幼狐 → 少年狐 → 成年狐 → 灵狐），进化有发光变身动画；Q 版大头小身子，毛发分层渐变、蓬松颈圈、大眼睛带睫毛，尾巴随进化变多（幼狐 1 条、少年狐 3 条、成年狐 6 条、灵狐 9 条金色大尾巴），灵狐带蓝色狐火和花瓣；散步是四肢轮换行走，尾巴波浪式自然摆动；头顶状态条是毛玻璃小胶囊；番茄钟专注时它坐下陪你，待办完成时它跳一下庆祝，倒计时 3 天内它举小牌子提醒。
- **桌宠小娲**：第二只宠物，灵蛇小女娲，金冠广袖、翡翠蛇尾、莲灯，飘着移动；每周一四阶段进化（小蛇女 → 少女 → 仙子 → 神女），莲灯越来越亮、入夜更亮；专属互动是莲灯许愿、喂莲子仙桃、云端玩耍、神话风碎碎念；其他功能与阿绒一致。
- **换宠物与陪伴方式**：状态面板底部点“换宠物”在阿绒和小娲之间切换，带小烟雾过渡动画，上次养哪只会被记住；两只各自独立存进化、亲密度、饱食度、隐藏状态和位置。任意一只到顶阶后解锁“随机换宠”和“一直陪伴”：随机默认关闭，不选就一直是原来的宠物；手动开启后每天第一次打开随机选一只出场；也可以锁定一只一直陪伴，锁定后不随机，随时能改。

## 功能

- **番茄钟**：专注 25 分钟 / 短休息 5 分钟 / 长休息 15 分钟，4 个番茄后自动进入长休息；环形进度、今日番茄数、今日专注时长、连续打卡天数；结束时有提示音；快捷键空格开始/暂停、R 重置、S 跳过。
- **待办清单**：添加、勾选（先画勾再扫删除线）、删除，按全部 / 进行中 / 已完成筛选，一键清除已完成。
- **重要日子**：添加日子与日期，自动算剩余天数，按最近排序；右上角会提醒最近的日子（名字、剩余天数、日期，当天显示“就是今天”）。

## 数据

待办、日子、番茄记录、小圆点位置和桌宠的进化进度、亲密度、饱食度、隐藏状态、位置都存在浏览器本地，关掉页面也不会丢；换浏览器或清缓存会清空。两只宠物各自独立存档，随机开关、锁定选择和当天随机记录也存在本地。

## 使用

直接用浏览器打开 `index.html` 即可；也可以部署到 GitHub Pages：

仓库 Settings → Pages → Branch 选择 `main`，保存后访问 `https://<用户名>.github.io/daymark/`。
