# Daymark · 每日记（静态版）

Windows 电脑屏幕的壁纸式个人桌面：全屏壁纸，番茄钟、待办清单、重要日子倒计时是附带工具，平时不显示，通过一个可拖动的小圆点加圆环菜单打开。单文件 `index.html`，无构建、无依赖，直接用浏览器打开即用，数据存在浏览器本地（localStorage）。

## 界面

- **壁纸桌面**：全屏动态壁纸，右上角是大时钟、日期、当日小结、倒计时提醒和每天夜读；没使用时小结行不显示，有内容才出现。三套壁纸主题都是真实图片打底（山水晨光、霓虹雨夜、极光星野，默认山水晨光，图片以内联 base64 嵌在单文件里）：动态只做轻的一层——照片缓慢推近、颗粒、暗角，山水加漂雾、雨夜加细雨丝、极光加光带呼吸和闪星；圆环菜单里新增“壁纸”扇区，点开可换主题，还能开关时钟、倒计时、夜读三个小组件，选择存在本地，下次打开还在；页面切到后台暂停动画，减弱动效时静止，图片加载失败回落到原来的静态水彩壁纸。
- **小圆点**：像苹果手机 AssistiveTouch 的小圆点，46px 半透明，可任意拖动，松手吸附到最近的屏幕边缘并藏起大半，只露约 15px；点一下打开圆环菜单。
- **圆环菜单**：五个扇形（红番茄钟、蓝待办、橙重要日子、玫瑰红桌宠、壁纸），指针方向决定高亮，点中心、点圆环外或按 Esc 取消，按 1 / 2 / 3 / 4 / 5 直接打开。
- **夜读**：每天自动抓人民日报客户端官网首页的最新一篇夜读，显示在日期下面：平时只留一个淡淡的朗读播放键，标题和摘要透明、直接落在壁纸上，鼠标移过去才逐行浮现（无日期标签、无来源行，点标题读原文，点播放键听朗读）；打开时自动抓，每小时复查一次，按顺序试四条路（直连官网、proxy.cors.dev、allorigins、codetabs）；抓到的文章存进本地历史（最多 7 篇），抓不到就显示历史里最新的一篇（前一天那篇），第一次打开时历史里已内置了当晚的一篇，所以卡片不会空着。
- **桌宠**：一次一只，住在左下角，平时会随机做小动作，可拖动、可一键隐藏（隐藏后左下角留个按钮点回来）；点它会有心情回应，长按、右键或圆环菜单里的“桌宠”扇区打开菜单和状态面板（摸摸、喂食、玩耍、睡觉、状态、音效开关）；它会隔几分钟碎碎念；宠物状态在圆环菜单的“桌宠”扇区里看（扇区上有状态小圆点：专注绿、休息蓝、睡觉灰、有提醒红脉冲）；摸摸喂食涨亲密度（陌生→熟悉→亲密→挚友），饱食度会慢慢下降，饿了会主动要吃的；每周一进一阶，进化改成每阶多一层光环并解锁新动作，进化有发光变身动画；番茄钟专注时它坐下陪你，待办完成时它跳一下庆祝，倒计时 3 天内它举小牌子提醒。状态面板里还有心情值（喂食、摸摸、玩耍、接球、专注陪伴都会影响，心情低时它会叹气、碎碎念也跟着变）、接小球游戏（抛球后在球落下时点它接住，连中计入最高纪录）和宠物日记（进化、新动作、喂食、玩耍、亲密度提升、接球纪录按日期记下来）。
- **四只宠物**：直接用 pet 仓库（dsh-plugin-pet）里的原画精灵表，逐帧动画（待机、散步、挥手、跳跃、入睡、等待、专注）：小娲（灵蛇小女娲，金冠广袖、翡翠蛇尾、莲灯）、小蝉（绯衣小金蝉，火焰莲冠、红袈裟、九环禅杖）、幽冥书生（青巾书箱、火耀星河长袍、踏幽蓝鬼火）、长乐仙子（银发凤冠、粉襦绿裙、花扇莲台）。每只配自己的专属互动和碎碎念；每周一进一阶共四阶，造型不变，每阶加一层光环并解锁新动作。
- **换宠物**：状态面板底部点“换宠物”在四只之间切换，带小烟雾过渡动画，上次养哪只会被记住；每只各自独立存进化、亲密度、饱食度、隐藏状态和位置。默认出场是小娲。

## 功能

- **番茄钟**：专注 25 分钟 / 短休息 5 分钟 / 长休息 15 分钟，4 个番茄后自动进入长休息；环形进度、今日番茄数、今日专注时长、连续打卡天数；结束时有提示音；快捷键空格开始/暂停、R 重置、S 跳过。面板有三个页签：计时、统计、氛围。统计页有每日打卡（连续天数、历史最长、近七天打卡点）、番茄连续天数、今日待办完成率、本周专注、近 7 天和近 4 周专注分钟柱状图，以及每周一自动生成的上周回顾。氛围页有 WebAudio 合成的白噪音（雨声、咖啡馆、风声、篝火，音量可调，可设专注时自动开启）和全屏专注模式（只留大倒计时和桌宠，Esc 退出）。
- **待办清单**：添加、勾选（先画勾再扫删除线）、删除，按全部 / 进行中 / 已完成筛选，一键清除已完成。
- **重要日子**：添加日子与日期，自动算剩余天数，按最近排序；右上角会提醒最近的日子（名字、剩余天数、日期，当天显示“就是今天”）。

## 数据

待办、日子、番茄记录、小圆点位置和桌宠的进化进度、亲密度、饱食度、隐藏状态、位置都存在浏览器本地，关掉页面也不会丢；换浏览器或清缓存会清空。四只宠物各自独立存档。打卡、连续天数、统计和宠物日记存在独立的本地存档（daymark-habits-v1）里。壁纸主题和小组件开关存在独立的本地存档（daymark-wallpaper-v1）里。

## 使用

直接用浏览器打开 `index.html` 即可；也可以部署到 GitHub Pages：

仓库 Settings → Pages → Branch 选择 `main`，保存后访问 `https://<用户名>.github.io/daymark/`。
